# Interactive Desk Fan 🌀

A clean, responsive, and interactive UI component simulating a modern desk fan built from scratch with **vanilla HTML, CSS, SVG, and JavaScript** — zero external libraries or frameworks.

## ✨ Features

- 🎨 **Pure CSS & SVG Design:** Custom realistic shading, dynamic wind particles, and glassmorphism UI card layout.
- ⚙️ **Inertia Physics Simulation:** Smooth acceleration and natural deceleration curves powered by logarithmic decay and `requestAnimationFrame`.
- 🕹️ **Interactive Controls:** Smooth ON/OFF state management and 3-speed selector.
- ⚡ **Zero Dependencies:** Extremely lightweight, fast loading, and easy to embed into any web project.

## 🚀 Tech Stack

- **HTML5** (Semantic structure & SVG components)
- **CSS3** (Glassmorphism, CSS variables, keyframe animations)
- **JavaScript** (DOM manipulation & animation frame loops)
